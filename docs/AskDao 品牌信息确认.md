# AskDao 品牌信息确认

## 1. 已确定品牌信息

| 项目 | 内容 |
|---|---|
| 中文品牌 | 问道 |
| 英文品牌 | AskDao |
| App Store 展示 | AskDao: I Ching Reflection |
| Logo 文案 | AskDao |
| Slogan | Ask the coins. Reflect with the Dao. |

## 2. 使用说明

- 中文品牌「问道」用于中文内部讨论、中文资料沉淀和后续中文传播场景。
- 英文品牌「AskDao」用于产品主品牌、海外用户沟通和英文视觉体系。
- App Store 展示名采用 `AskDao: I Ching Reflection`，突出品牌名与核心使用场景。
- Logo 中优先使用 `AskDao`，保持英文用户识别成本低。
- Slogan 固定为 `Ask the coins. Reflect with the Dao.`，对应三钱起卦与自省定位。

## 3. 与 MVP PRD 的关系

本文件用于补充 MVP PRD 中「确认英文产品名与视觉方向」相关事项。目前已确认品牌命名与核心标语，后续视觉方向、图标风格、字体和色彩系统可另行生成调研文档继续沉淀。
