# 《了凡四训》公众号书评引流方案

## 一、定位与目标

- **渠道**：个人订阅号，单篇试水
- **受众**：对传统文化、自我成长有兴趣的泛读者（非术数圈），文章内不出现排盘术语
- **主 KPI**：小程序卡片点击 → 首页访问（`source=gzh_liaofan` 渠道参数识别）
- **参考指标**：阅读量、分享率（在看 / 转发朋友圈）

## 二、文章结构（成稿蓝图）

角度采用「应验钩子型」：以"逐条记录、逐条应验"为叙事主线，中段翻转立场，结尾植入产品。

1. **钩子**：嘉靖年间，袁了凡遇孔先生，一生功名、俸禄、寿数被逐年批出，具体到某年考第几名
2. **应验**：此后二十年了凡逐条记录核对，"其言皆验"，连"食米九十一石五斗出贡"的细节都不差
3. **转折**：栖霞山遇云谷禅师——"命由我作，福自己求"，立场从"算得准"翻转为"记录与自省"
4. **点题**：《了凡四训》真正的遗产是记录的传统：功过格、每日一记、事后回看。准不准是玄学，记不记是方法
5. **植入**：今天问一件小事、记一次应验，不必再用毛笔——引出「一念六壬」：问小事、每日最多三问、事后可记应验
6. **收尾 + 小程序卡片**

全文 1800–2500 字（公众号最佳阅读时长区间）。

标题（规避风控词，不用"算命/占卜"）：

> **《三百年前，他把一生的预言逐条核对了二十年》**

## 三、植入与转化路径

- **前置动作**：公众号后台「广告与服务 → 小程序管理」关联「一念六壬」，需小程序管理员扫码确认；个人订阅号可免费关联
- **植入位两处**：
  - 第五节首次提及处：低调的文字/图片小卡
  - 文末：完整小程序卡片（主转化位）
- **卡片路径**：`pages/home/index?source=gzh_liaofan`
  - 首页 `onLoad` 的 `page_view` 埋点自带 `source`，零代码改动即可在分析中区分该渠道
- **兜底**：文末附小程序码图片，防止未关联成功或卡片渲染失败

## 四、合规与调性

- 全文定位书评 / 传统文化，措辞用"参考、自省、记录"，不出现"灵验保证""必中"类表述
- 标题与正文规避"算命""占卜"等风控词，用"预言""批命"替代
- 调性与小程序内免责声明、"问小事"定位一致；不涉健康、财务、重大决策话题
- 封面图：浅色纸张 + 水墨质感（古籍 + 毛笔），与小程序视觉同源

## 五、发布检查清单与试水复盘

- [ ] 公众号关联小程序并通过管理员确认
- [ ] 预览态检查：卡片可点、路径参数正确、朋友圈分享卡片文案正常
- [ ] 群发时间：工作日 21:00–22:00（文化类阅读高峰）
- [ ] 发布后 24h / 72h 记录：阅读量、分享数、`source=gzh_liaofan` 访问数
- [ ] 复盘阈值：卡片点击率 > 5% 或单日新访问 > 100 → 启动第二篇（"掐指一算"小六壬科普篇）
