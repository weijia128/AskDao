# 易经 / 六爻 / 六壬名言词句素材

> 用途：后续用于生成海报、插画、卡面、社媒图文等视觉素材。  
> 说明：**《周易》部分尽量保留古籍原句与篇章出处**；六爻、六壬部分多为术数口诀、术语化短句或便于视觉生成的整理句，建议作为“灵感文案/画面题眼”使用。若要做严肃出版，请再按版本校勘原文。

## 二、六爻 / 纳甲筮法灵感短句

> 这一组更适合做“占筮感、卦象感、卡面文案”。多为术数常用语、口诀化表达或整理句。

| 词句 | 备注 | 适合画面意象 |
|---|---|---|
| 月建为万卜之提纲，日辰为六爻之主宰 | 六爻常用判断纲领 | 月轮、日晷、六条爻线 |
| 卦有六爻，爻分阴阳 | 基础术语整理 | 六线、黑白、竹签 |
| 爻动则变，变中见机 | 整理句 | 断裂线、流动墨迹 |
| 世为己，应为彼 | 世应关系 | 两端相望、镜像人物 |
| 世应相生，事有相成 | 世应生克整理 | 两股相生的气流 |
| 世应相克，事多阻隔 | 世应生克整理 | 对峙、屏障、交叉线 |
| 用神为所问之事 | 用神概念 | 被圈出的符号、中心光点 |
| 用神得地，所求有依 | 整理句 | 根系、土地、稳定构图 |
| 用神无根，事多漂泊 | 整理句 | 浮萍、无根之木 |
| 原神宜生，忌神宜制 | 六亲/六神关系整理 | 生克箭头、阴阳棋盘 |
| 动爻生用，暗处有助 | 整理句 | 暗光、伸出的手 |
| 动爻克用，前路有阻 | 整理句 | 破碎道路、阻挡的石门 |
| 静逢冲则动，动逢合则绊 | 常见断法口诀 | 被风吹动的线、缠绕红绳 |
| 六冲主散，六合主合 | 常见判断语 | 分裂圆环、闭合圆环 |
| 旬空非无，待时而实 | 空亡概念整理 | 空白格、等待填满 |
| 伏神藏象，飞神露机 | 飞伏神整理 | 半透明符号、暗层纸张 |
| 父母主文书，官鬼问功名 | 六亲取象 | 文书、官印、案卷 |
| 妻财主财帛，子孙解忧惊 | 六亲取象 | 铜钱、孩童、安宁 |
| 兄弟分财气，亦主同行人 | 六亲取象 | 并行身影、分开的钱纹 |
| 一卦既成，吉凶由象 | 整理句 | 卦盘定格、光暗分野 |

## 三、大六壬 / 六壬灵感短句

> 六壬部分多取“大六壬”的四课、三传、天将、贵人等意象；也可与小六壬的“时辰、流转、吉凶六象”视觉气质合用。

| 词句 | 备注 | 适合画面意象 |
|---|---|---|
| 月将加时，天地成盘 | 六壬起课意象整理 | 天盘地盘、月影、罗盘 |
| 四课定其体，三传见其用 | 六壬结构整理 | 四格与三道路径 |
| 初传发端，中传转机，末传归宿 | 三传过程整理 | 三段阶梯、三重门 |
| 发用为机，传变为势 | 三传判断整理 | 第一束光、流向远处 |
| 干为人，支为宅 | 六壬常用取象 | 人影与屋宇、内外关系 |
| 课传既成，吉凶乃著 | 整理句 | 卷轴展开、符号显现 |
| 神将临位，象意自明 | 天将意象整理 | 十二神将、星位 |
| 贵人临身，暗中有扶 | 贵人意象 | 高处灯火、扶持之手 |
| 青龙主喜，朱雀主信 | 天将取象整理 | 青龙、书信、红鸟 |
| 白虎主刑，玄武主隐 | 天将取象整理 | 白虎、黑水、暗影 |
| 六合主和，勾陈主滞 | 天将取象整理 | 结绳、泥土、停滞线条 |
| 螣蛇主惊，天空主虚 | 天将取象整理 | 蛇影、空白、幻象 |
| 太常主礼，天后主阴 | 天将取象整理 | 礼器、水月、帷幕 |
| 昼夜分途，贵人顺逆 | 贵人顺逆意象 | 白昼/夜晚双盘 |
| 甲戊庚牛羊，乙己鼠猴乡 | 贵人口诀上句 | 十二生肖环、天干 |
| 丙丁猪鸡位，壬癸兔蛇藏 | 贵人口诀中句 | 生肖与星宿 |
| 六辛逢马虎，此是贵人方 | 贵人口诀下句 | 马虎双形、方位图 |
| 天时地利，神将相参 | 整理句 | 天象、地纹、神将剪影 |
| 一念入课，万象归盘 | 视觉文案整理 | 提问之念、万象旋入罗盘 |
| 问在此时，象起此刻 | 视觉文案整理 | 时辰牌、瞬间定格 |

## 六、出处与核对建议

- 《周易》原句可优先核对：中华书局本《周易》、上海古籍本《周易译注》、中国哲学书电子化计划、维基文库。
- 六爻可参考：《火珠林》《卜筮正宗》《增删卜易》等不同版本。
- 大六壬可参考：《大六壬课经集》《御定六壬直指》《大六壬探原》等。
