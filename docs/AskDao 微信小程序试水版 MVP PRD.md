# AskDao 微信小程序试水版 MVP PRD

## 1. 背景与策略调整

AskDao 原始方向是面向海外用户的传统文化 AI App。当前阶段调整为先做国内微信小程序试水，不优先做原生 App，也暂不考虑付费。

试水阶段重点验证两件事：

- 用户是否愿意在微信内使用「问一问」服务。
- 用户是否愿意保存并分享问道结果卡片，从而带来自然传播。

小程序首版不做复杂商业化、不做完整命理工具、不做专家咨询，而是用轻量、神秘、克制的方式提供一个有仪式感的传统文化问事体验。

## 2. 产品定位

问道是一款偏神秘仪式感的轻量微信小程序。用户可以通过小六壬、金钱卦等传统文化形式，对当下困惑获得一个含蓄回应。

产品不强调预测准确性，不承诺结果，不引导用户依赖占断。核心价值是：

- 给用户一个安顿情绪的仪式。
- 给问题一个新的观察角度。
- 给行动一个温和提醒。
- 给微信传播一个好看的分享卡片。

一句话定位：

> 一个有东方仪式感的轻量问道小程序。

## 3. 目标用户

### 核心用户

- 年龄：20-40 岁。
- 场景：遇到选择、关系、事业、状态问题时，希望获得一个带仪式感的回应。
- 兴趣：传统文化、玄学内容、塔罗、星座、心理测试、情绪疗愈、生活方式内容。
- 使用习惯：愿意在微信群、朋友圈、小红书等场景分享结果图。

### 暂不服务

- 专业命理用户。
- 期待精确断事、改命、转运的人。
- 需要医疗、法律、金融、投资建议的人。
- 想通过平台获得真人咨询的人。

## 4. MVP 目标

首版不验证付费，优先验证传播与留存。

核心指标：

- 访问人数。
- 起问开始率。
- 起问完成率。
- 保存卡片率。
- 分享卡片率。
- 次日留存。
- 7 日留存。

阶段性成功信号：

- 用户打开后能在 1 分钟内完成一次问道。
- 结果卡片足够有分享欲。
- 用户愿意因「今日再问一次」或「换一种问法」再次打开。
- 新用户从分享卡片进入后能快速理解并开始使用。

## 5. 首版功能范围

### 必做

1. **问道首页**
   - 首屏直接展示问道方式卡片。
   - 不做复杂导航，不设置额外的「问法类型」选择页。
   - 顶部展示占前提示：

```text
不诚不占，不疑不占，不义不占
```

   - 小字解释：

```text
心不诚，则象不明；事无疑，则不必问；所问不义，则不取象。
```

2. **问道方式卡片**
   - 首页直接展示不同方式：
     - 小六壬
     - 金钱卦
   - 每张卡片包含一句短提示和适合场景。

3. **小六壬**
   - 卡片小字：

```text
遇事不决，六壬决断
```

   - 适合快速问事、短期选择、今日去留。
   - 首版结果只输出三档：
     - 阻
     - 平
     - 顺

4. **金钱卦**
   - 卡片小字：

```text
三钱六掷，观象自省
```

   - 适合复杂问题、内心困惑、关系变化。
   - 首版保留六次掷钱的仪式感。
   - 结果可展示卦象信息，但最终表达仍收束到温和建议。

5. **结果页**
   - 结果不使用绝对预测语言。
   - 核心结构：
     - 结果档位：阻 / 平 / 顺。
     - 一句签语。
     - 一段解释。
     - 一个行动提醒。
     - 一个反思问题。
   - 默认不展示用户原问题，保护隐私。

6. **保存分享卡片**
   - 生成适合朋友圈的竖版结果卡片。
   - 卡片内容包括：
     - 产品名：问道 / AskDao。
     - 问道方式：小六壬或金钱卦。
     - 结果档位：阻 / 平 / 顺。
     - 签语。
     - 简短行动提醒。
     - 小程序码。
   - 用户可保存到相册，再发朋友圈或群聊。

7. **分享到朋友圈**
   - 支持通过微信小程序分享能力进入结果摘要页或问道入口页。
   - 分享落地页不能依赖完整用户状态，应能直接引导新用户开始问道。

### 暂不做

- 付费、订阅、点数包。
- 真人咨询。
- 八字、紫微斗数、风水罗盘、复杂命盘。
- 社区、评论、好友关系。
- 强账号体系。
- 广告变现。
- 复杂历史记录云同步。
- 医疗、法律、金融、投资等问题的具体建议。

## 6. 核心用户路径

### 路径 A：小六壬快速问事

1. 用户打开小程序。
2. 看到「不诚不占，不疑不占，不义不占」。
3. 点击「小六壬」卡片。
4. 心中默念或输入一句所问。
5. 完成轻量起问动作。
6. 获得「阻 / 平 / 顺」结果。
7. 查看签语、解释、行动提醒和反思问题。
8. 保存结果卡片。
9. 发朋友圈或群聊。
10. 新用户通过卡片进入小程序。

### 路径 B：金钱卦仪式问道

1. 用户打开小程序。
2. 点击「金钱卦」卡片。
3. 输入问题，或选择心中默问。
4. 连续六次掷钱。
5. 系统生成卦象与变化。
6. 展示结果档位、签语、自省解释和行动提醒。
7. 用户保存或分享卡片。

## 7. 结果表达规则

### 三档结果

| 档位 | 含义 | 表达方向 |
|---|---|---|
| 阻 | 此事有滞，宜缓不宜急 | 提醒暂停、观察、避险 |
| 平 | 势在中途，需再观察 | 提醒等待、确认、蓄力 |
| 顺 | 气机渐开，可小步推进 | 提醒行动、推进、把握时机 |

### 文案原则

允许使用：

- 气机。
- 时势。
- 阴阳。
- 象。
- 宜缓。
- 可进。
- 自省。
- 观心。
- 签语。

避免使用：

- 必中。
- 必然。
- 保证。
- 改命。
- 转运。
- 预测结局。
- 今日必发。
- 破解灾祸。
- 付费化解。

### 免责声明表达

结果页底部应有轻量提示：

```text
问道结果仅作传统文化体验与自我参考，不作为现实决策的唯一依据。
```

## 8. 分享卡片设计要求

分享卡片是首版传播核心，不是附属功能。

### 内容要求

- 不展示用户原问题。
- 不展示过长解释。
- 不制造焦虑。
- 重点呈现签语和结果氛围。
- 明确展示小程序码，方便回流。

### 建议版式

- 顶部：问道 / AskDao。
- 中部：结果档位大字，例如「顺」。
- 中下：签语。
- 底部：行动提醒、小程序码。

### 视觉方向

- 玄黑。
- 宣纸白。
- 朱砂红。
- 暗金铜钱。
- 轻微烛光、粒子或铜钱落定动效。

视觉要有东方神秘感，但保持克制，不做廉价恐吓或夸张营销风。

## 9. 留存机制

首版留存依靠轻功能，而不是签到、任务或付费权益。

可做：

- 今日可问一次。
- 今日签语。
- 最近问道记录本地保存。
- 收藏有启发的结果。
- 每日不同引导语。

首版记录可以先本地保存，不强制登录。

## 10. 合规与内容边界

产品必须保持传统文化体验、自省启发、娱乐参考定位。

不做：

- 明示或暗示准确预测未来。
- 对医疗、法律、金融、投资问题给具体建议。
- 恐吓用户。
- 诱导付费化解。
- 收集生辰八字、人脸、手相、证件号等高敏信息。
- 诱导分享。

对高风险问题，应提示用户寻求现实帮助或专业意见。

## 11. 后续阶段

### 试水版

- 小六壬。
- 金钱卦。
- 结果页。
- 保存分享卡片。
- 基础留存。

### V1.1

- 今日一问。
- 节气日课。
- 更多卡片模板。
- 更完整的本地历史记录。
- 简单数据看板。

### App 阶段

当小程序验证传播和留存后，再考虑原生 App。App 版本可承接：

- 更完整的历史记录。
- 更强的 AI 解读。
- 更丰富的传统文化内容。
- 订阅或会员体系。
